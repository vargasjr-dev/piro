# Borealis

Borealis is a standalone Piro research experiment focused on a functional
fast/slow self-updating language model.

The experiment owns its architecture under
`architectures/borealis/`. It is intentionally separate from the completed
Ashfall experiment and is currently research-only: the Modal training and
inference worker does not yet support the Borealis template.

See [`architectures/borealis/README.md`](./architectures/borealis/README.md) for
the model contract and validation commands.
